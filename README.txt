AIFINDER PUBLISHABLE WEBSITE
1. Replace YOUR-DOMAIN.com in index.html, robots.txt and sitemap.xml.
2. Replace YOUR-EMAIL@example.com in contact.html and privacy.html.
3. Upload all files to a GitHub repository.
4. GitHub: repository Settings > Pages > Deploy from a branch > main > / (root) > Save.
5. Your GitHub Pages URL will be shown in Settings > Pages.
6. Optional: connect a custom domain through Settings > Pages.
7. For ads, replace the "Advertisement" placeholders in index.html with the ad network's official code after approval.
8. For affiliate links, use programs you are accepted into and disclose the relationship.
